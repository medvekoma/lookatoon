# Changelog

## [0.1.2]

- Column types are now detected per-column instead of per-cell, so numeric alignment and null styling are consistent across the entire column
- Numeric and boolean columns no longer receive a distinct color
- Null cells in numeric columns are right-aligned to match the column layout

## [0.1.1]

- Improved README with a sample `.toon` file and updated example description

## [0.1.0]

- Initial release: `.toon` file viewer with tabular rendering
